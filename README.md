# CE5011 - Machine Vision and Image Processing

Coursework for CE5011 at the University of Limerick.

## Assignment 1

[Bottle fill level inspection notebook](Assignment1/Section1_assignment1.ipynb)

The notebook uses Gaussian smoothing, Canny edge detection, bottle masks, morphological closing and Hough line detection to inspect liquid levels. It includes an optional thresholding experiment and a reflection on the method and its limitations.

Python dependencies are listed in [requirements.txt](Assignment1/requirements.txt). The notebook downloads its input image, so running it requires an internet connection.

The example notebooks in `Assignment1/resources` are supplied teaching materials retained with their original content and attribution.
